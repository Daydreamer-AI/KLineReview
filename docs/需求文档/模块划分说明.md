# 需求文档目录与模块划分说明

> 本文件定义 `docs/需求文档/` 的目录结构、模块划分与放置规则（版本/模块结构于 2026-08-19 确认建立）。

## 1. 目录结构

```text
docs/需求文档/
├── 需求文档模板.md          # 模板，新增需求时复制使用，不随版本/模块移动
├── 模块划分说明.md          # 本文件
└── <版本>/                  # 如 v1.0、v1.1，与 release 分支 / tag 对应
    ├── 行情/                # 主界面、行情展示、K 线图表
    ├── 复盘/                # 回放、模拟交易
    ├── 数据抓取/            # baostock / akshare 数据源
    ├── 数据库/              # db_base、数据存储与迁移
    ├── 指标/                # 技术指标计算与配置
    ├── 后台任务/            # 线程池与任务
    ├── 配置与日志/          # 配置、日志
    └── 跨模块/              # 无法归入单一模块的需求
```

## 2. 放置规则

1. 需求文档路径：`docs/需求文档/<版本>/<模块>/<YYYYMMDD>-<功能名>.md`；
2. 一个需求只放一个位置，按**主要影响模块**归类；
3. 无法判定主模块时放入 `跨模块/`；
4. 模板固定在 `docs/需求文档/需求文档模板.md`，不随版本/模块移动；
5. 新版本迭代开始时创建对应 `<版本>/` 目录（如 `v1.1/`）；旧版本目录保留，不迁移。

## 3. 模块划分（参考）

| 模块目录 | 典型内容 | 对应代码区域（参考） |
| --- | --- | --- |
| 行情 | 主窗口、首页、K 线/指标展示、设置页 | `src/gui/qt_widgets/main`、`MComponents/indicators`、`src/gui/qt_widgets/setting` |
| 复盘 | 回放、模拟交易、收益曲线、弹幕选股 | `src/gui/qt_widgets/MComponents/review`、`review_demo_trading_manager` |
| 数据抓取 | 数据源适配（Baostock）、按需取数 | `src/processor`、`src/thread/baostock_data_fetch_task.py` |
| 数据库 | 存储、表结构、连接池 | `src/db_base` |
| 指标 | 指标算法、指标配置 | `src/indicators`、`indicators_config_manager` |
| 后台任务 | 任务池、任务生命周期 | `src/thread` |
| 配置与日志 | 配置管理（UI/指标）、日志系统 | `src/common/config.py`、`config_manager`、`logging_manager` |
| 跨模块 | 涉及多个模块、无法单一归类 | — |

> 模块清单可在实际使用中增删调整；调整后同步更新本文件与 [docs/开发规范/日常开发维护流程.md](../开发规范/日常开发维护流程.md)。
