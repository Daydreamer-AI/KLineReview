## 1. 背景与目标

- 背景：
  - 复盘按“复盘基准时刻 as_of”本地聚合上级周期，包含 as_of 且未走完的周期显示为进行中 bar（`is_complete=False`），例如周中复盘时当周 bar 只聚合到复盘日。
  - 此前点击“前进”一律把复盘索引 +1：进行中的当前 bar 被直接跳过，补全后的形态（如完整周）只能作为历史 bar 出现，用户无法“先把当前 K 线看完再前进”。
  - 配置项 `cfg.ctfEnabled`（设置页“Operation”分组，默认 False）已经存在，但没有接线到前进逻辑。
- 目标：
  - 前进时若当前 bar 未走完，先按 `cfg.ctfEnabled` 决定是否连续前进：
    - `False`（默认）：本次前进只把当前未走完 K 线补全为完整 K 线，复盘位置不动；用户再次点击前进才显示下一根完整 K 线；
    - `True`：补全当前未走完 K 线并自动前进，显示下一根完整 K 线（等价于此前的行为）。
  - 补全只影响当前 bar，不移动复盘位置、不截断后续周期数据。

## 2. 需求描述（功能点）

- [x] 前进逻辑接线 `cfg.ctfEnabled`（`indicators_view_widget.step_forward`）：
  - `ctfEnabled=False` 且当前 bar 未走完：只调用补全流程，本次前进到此结束（不复用原前进分支）；
  - `ctfEnabled=True`：直接沿用原前进逻辑——移动到下一根时上一根已按完整周期重算（即“补全当前未走完 K 线并显示下一根完整 K 线”），保持原有前进语义与模拟交易判定次数不变；
  - 当前 bar 已走完（或无 `is_complete` 列的行情视图）时行为不变。
- [x] 补全未走完 bar（`_complete_unfinished_current_bar` + `_get_unfinished_bar_complete_as_of`）：
  - 判定“未走完”以当前周期数据 `is_complete` 列当前索引的取值为准；
  - 补全用 as_of 取当前 bar 所属周期内**最后一根基周期 bar 的时刻**，据此调用既有 `_refresh_derived_period_data` 重建本周期数据：该周期按完整周期聚合（`is_complete=True`），且 as_of 落在周期内，不会把下一周期判为进行中或被截断；
  - 补全后就地按同一索引重绘（`update_chart`），索引、进度条数值不变；模拟交易价格/时间随补全后的 bar 刷新；
  - 基周期数据本身不足（如进行中当日分钟数据未走完）导致无法补全时返回 False，按普通前进处理，避免“点击无反应”。
- [x] 周期无关性：分钟级目标周期以最小分钟基周期、日线及以上以日线基周期取该周期内最后一根基周期 bar 时刻，日/周/月/分钟级共用同一补全规则。
- [x] 设置项文案（`review_setting_interface.py`）：`Complete the forward` 卡片副标题改为“补全当前未走完 K 线；开启后继续前进到下一根”。
- [x] 公开复用点（`period_aggregator.get_base_timestamps`）：供补全逻辑按聚合器同一规则解析基周期时间戳，避免重复实现。

## 3. 验收标准

- [x] 周中复盘（如 2026-06-03 周三）切到周线，当前周 bar `is_complete=False`；
- [x] `ctfEnabled=False`：第一次前进后索引不变、当前 bar 变为完整周（周一~周五、`is_complete=True`、日期标签为当周最后交易日、收盘价为周五收盘），第二次前进才移动到下一周且该周完整；
- [x] `ctfEnabled=True`：一次前进即补全当周并移动到下一根完整周线，原进行中周在图上显示为完整周；
- [x] 月线同理（2026-06-03 复盘：补全后日期标签为 2026-06-30）；
- [x] 当前 bar 已走完时，`ctfEnabled` 取值不影响前进行为；
- [x] 补全前后周期数据行数一致，复盘索引不漂移；
- [x] `python -m unittest discover -s tests -v` 全绿（新增 `TestForwardOnUnfinishedBar` 4 项）。

- 兼容性与风险：
  - 补全会显示当前周期内 as_of 之后的走势（即“把当前 K 线看完”），这是本需求的目标语义；此前该形态会在点击前进后立即出现，故不引入额外数据泄漏。
  - `steps>1`（前进 10 步）时若当前 bar 未走完，一次点击只完成补全，不额外前进（与“补全即本次前进”的语义一致）。
  - 自动播放路径（`slot_animation_step` → `step_forward`）同样遵循该规则：未走完的 bar 会先停一帧补全再继续。
