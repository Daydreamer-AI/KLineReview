## 1. 背景与目标

- 背景：
  - 复盘页日线向周线等上级周期切换时，周线数据直接来自远程 Baostock；Baostock 各周期接口只返回“完整周期”bar（工作日 18:00 后更新当天日线、每周最后交易日更新当周周线、月线以上同理），未走完的周期在远程数据中不存在。
  - 因此周中复盘（如复盘到周三）时，当周要么缺失、要么以“完整周”形式出现（bar 内包含周四/五的“未来”数据），复盘语义不正确；现有 `init_animation` 用 `checked_id >= 8 → date < start_date` 硬编码规避，与初始加载路径 `date <= start_date` 不一致，存在周五边界误伤，且无法表达“进行中（未走完）bar”。
  - 分钟级、月线等扩展时，若继续按周期各写一套匹配逻辑，将出现第三套、第四套特判。
- 目标：
  - 复盘链路不再依赖远程上级周期接口；周线等上级周期由基周期（日线）按“复盘基准时刻 as_of”本地聚合生成，未走完的周期显示为进行中 bar。
  - 周期切换锚定统一为“目标周期 bar 的周期开始时刻 <= as_of 的最后一根”，初始加载与切换路径一致，天然覆盖周五边界与部分周。
  - 预留分钟级扩展：聚合器与锚定逻辑按日期+时间维度通用设计，分钟级数据获取恢复时无需另写一套。

## 2. 需求描述（功能点）

- [ ] 通用周期聚合器（新增 `src/processor/period_aggregator.py`）：
  - `aggregate_period(base_df, period, as_of=None)`：按目标周期边界（周=周一、月=1 日、日=当日、分钟=bar 开始时刻）分组聚合 open/high/low/close/volume/amount；
  - 输出 bar 日期取“该周期内最后一根基周期 bar 的时刻”（未走完时即 as_of 所在基周期 bar 的时刻）；
  - 包含 as_of 且未走完的周期 bar 只聚合 as_of 之前的基周期数据，并标记 `is_complete=False`，其余 bar 保持完整；
  - 聚合后复用 `default_indicators_auto_calculate` 计算指标列，列结构与现有周期数据一致（额外增加 `is_complete`）。
- [ ] 复盘加载链路改造（`review_widget.py`）：
  - 保留 `_DEFAULT_LOAD_PERIODS`（日线、周线）作为展示周期；新增“基周期”概念（默认 `[DAY]`），远程只按顺序拉取基周期；
  - `_all_periods_ready` / `_period_in_cache` 改为按基周期判断缓存；
  - `_on_all_periods_loaded` 对非基周期展示周期调用 `aggregate_period` 本地生成，不再拉取远程周线。
- [ ] 锚定逻辑统一（`indicators_view_widget.py`）：
  - `init_animation` 移除 `checked_id >= 8` 特判与 `<`/`<=` 两套规则，统一为“周期开始时刻 <= as_of 的最后一根 bar”（进行中 bar 也包含）；
  - 初始加载（b_init）与周期切换路径共用同一匹配函数；
  - 分钟级：as_of 带时间，周期开始 = bar 结束时刻 - 周期时长（当前分钟级获取仍屏蔽，作为扩展预留）。
- [ ] 展示增强（可选，后续）：KLineWidget 对 `is_complete=False` 的 bar 做区分渲染（如半透明/虚线），或状态栏提示“当前 bar 未走完”。

## 3. 验收标准

- [ ] 周中复盘（如周三）切到周线：当周 bar 显示为周一~周三聚合的进行中 bar，不含周四/五数据；
- [ ] 复盘日期为周五时，当周完整周线正常显示，不再被 `<` 跳过；
- [ ] 直接以周线加载与日线切周线，同一复盘日期锚点一致；
- [ ] 复盘加载只远程拉取日线基周期，不再触发远程周线拉取；
- [ ] 上级周期数据含 `is_complete` 列，聚合后指标列（MA/MACD/KDJ/RSI/BOLL/量比等）正常；
- [ ] 冒烟验证：从项目根目录运行 `python ./src/main.py`，`data/logs` 无新增 ERROR/异常。

## 4. 影响范围

- 涉及模块/文件：
  - `src/gui/qt_widgets/MComponents/review_widget.py`（加载链路：基周期拉取 + 上级周期聚合）
  - `src/gui/qt_widgets/MComponents/indicators/indicators_view_widget.py`（锚定统一）
  - `src/processor/period_aggregator.py`（新增，通用周期聚合器）
  - `src/thread/baostock_data_fetch_task.py`（周线分支不再被复盘链路使用，保留不删）
- 涉及数据/数据库：无 schema 变更；复盘仍不落库。
- 兼容性与风险：
  - `IndicatorsViewWidget` 为共享组件，改动集中在复盘模式锚定逻辑与非分钟级路径；
  - 周线数据由本地聚合生成后，change_percent/turnover_rate 与 Baostock 远程值可能存在细微差异（周涨跌幅按周收盘计算、换手率为日线求和近似），不影响图表展示；
  - 分钟级数据获取仍屏蔽，分钟路径改动仅作扩展预留，不在本次验收范围。
