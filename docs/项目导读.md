# KLineReview 项目导读

> 说明：本文档基于对仓库代码的静态阅读生成（仅分析，未改动任何代码）。文中所有路径都是“相对项目根目录”的路径，例如 `src/main.py` 指 `KLineReview/src/main.py`。写作目标是让第一次接触这个项目的人也能快速看懂它。

## 一分钟看懂这个项目

这是一个 **A 股股票行情数据的“下载 → 本地存储 → 画图分析 → 历史回放复盘 → 模拟交易”一体化桌面工具**。你可以把它理解成一个带“时光机”的炒股练习软件：先下载历史 K 线数据存到本地数据库，然后在图形界面里打开任意一只股票、把时间拨回到过去的某一天，像看动画一样逐步回放 K 线，同时可以模拟买入/卖出，看看自己的策略在当时会不会赚钱。

证据：[README.md](README.md) 第一句“一个基于 akshare、baostock 的股票数据处理和技术分析工具，自带回放复盘功能”，以及 [src/gui/qt_widgets/MComponents/review_widget.py](src/gui/qt_widgets/MComponents/review_widget.py) 中的回放/模拟交易界面。

## 1. 项目要解决什么问题

**结论：把“看行情、算指标、复盘历史、验证买卖想法”这件事从手工、碎片化的工作，整合成一个本地化的桌面软件。**

具体拆开看，它解决了这几个痛点：

1. **数据获取麻烦**：A 股历史行情分散在多个数据源。项目用 baostock 拉取日线/周线/分钟线，用 akshare 拉取股票列表、板块、市值、筹码分布等扩展数据。
   - 证据：[src/processor/baostock_processor.py](src/processor/baostock_processor.py)、[src/processor/ak_stock_data_processor.py](src/processor/ak_stock_data_processor.py)
2. **数据存储混乱**：每只股票的 K 线单独存成一个 SQLite 数据库文件，并提供统一读写接口，避免每次都去联网。
   - 证据：[src/db_base/stock_db_base.py](src/db_base/stock_db_base.py)（每只股票一个库）、[src/manager/bao_stock_data_manager.py](src/manager/bao_stock_data_manager.py)（统一管理入口）
3. **看图分析**：在界面上画出 K 线和 MACD、KDJ、RSI、BOLL、MA 等技术指标，并支持自定义指标参数。
   - 证据：[src/gui/qt_widgets/MComponents/indicators/](src/gui/qt_widgets/MComponents/indicators/)、[src/indicators/stock_data_indicators.py](src/indicators/stock_data_indicators.py)
4. **回放复盘**：把时间拨回历史某一天，让 K 线像播放动画一样逐步推进，配合当时的盘面做决策练习。
   - 证据：[src/gui/qt_widgets/MComponents/review_widget.py](src/gui/qt_widgets/MComponents/review_widget.py)、[src/gui/qt_widgets/MComponents/indicators/indicators_view_widget.py](src/gui/qt_widgets/MComponents/indicators/indicators_view_widget.py) 中的 `init_animation`/`start_animation`
5. **模拟交易**：在回放过程中模拟买入/卖出（按 K 线最高/最低价撮合挂单），统计收益曲线，练习仓位管理。
   - 证据：[src/manager/review_demo_trading_manager.py](src/manager/review_demo_trading_manager.py)

## 3. 程序入口在哪里

**结论：程序入口是 `src/main.py`，从项目根目录执行 `python ./src/main.py` 启动。**

入口文件的启动步骤（[src/main.py](src/main.py)）：

1. 把项目根目录和自定义组件目录加入 `sys.path`（这样后面才能 `import` 到 `gui`、`manager` 等包）。
2. `setup_high_dpi_support()`：设置高分屏缩放相关环境变量（兼容不同 Qt 版本）。
3. `setup_logging(...)`：初始化日志，日志写到 `./data/logs`（[src/manager/logging_manager.py](src/manager/logging_manager.py)）。
4. 创建 `QApplication`，加载 `:/theme/default/main.qss` 全局样式。
5. 创建主窗口 `MainWidget` 并显示，进入 Qt 事件循环 `app.exec_()`。

主窗口 `MainWidget`（[src/gui/qt_widgets/main/main_widget.py](src/gui/qt_widgets/main/main_widget.py)）内部有三个页面，通过左侧按钮切换：

- 首页（HomeWidget）：数据下载/更新入口
- 行情页（MarketHomeWidget）：股票列表 + K 线图，**程序启动默认显示这一页**
- 复盘页（ReviewWidget）：历史回放 + 模拟交易

⚠️ **新手注意**：程序大量使用相对路径（如 `./src/gui/.../Xxx.ui`、`./data/logs`），所以必须从项目根目录启动，不要在 `src` 目录里运行 `python main.py`。

## 5. 从启动到核心功能执行的关键调用链

**结论：启动后程序会先在后台把本地行情加载进缓存，之后“行情页展示”和“复盘回放+模拟交易”都围绕这条数据链路展开。**

### 5.1 启动 → 加载数据 → 展示行情

```
src/main.py
  └─ MainWidget（创建首页/行情页/复盘页，默认显示行情页）
       └─ HomeWidget.__init__ → init_processors()
            ├─ AKStockDataProcessor().initialize()      # 读股票列表缓存
            └─ BaoStockProcessor().initialize()          # bs.login() 登录 baostock
                 └─ BaoStockProcessor().start_background_loading()
                      └─ BaseThreadWorker（后台线程）
                           └─ BaostockDataManager.load_1d_local_stock_data()
                                └─ StockDbBase（读 ./data/database/stocks/db/baostock 下的 SQLite）
                           → 完成时发出 sig_stock_data_load_finished 信号
                                └─ MarketHomeWidget.slot_bao_stock_data_load_finished
                                     └─ MarketWidget（行情页）
                                          └─ BaostockDataManager.get_all_lastest_row_data_dict_by_period_auto()   # 股票卡片列表
                                          └─ slot_stock_card_clicked(data)（点击股票）
                                               ├─ BaostockDataManager.get_stock_data_from_db_by_period_with_indicators_auto(code, period)
                                               ├─ IndicatorsViewWidget.set_stock_data(code, {period: df})  # 外部注入
                                               └─ IndicatorsViewWidget.update_chart(data)  # PyQtGraph 画 K 线 + 指标
                                          └─ 周期切换 → IndicatorsViewWidget.sig_period_changed
                                               └─ MarketWidget.slot_period_changed → 外部取数注入后刷新图表
```

对应证据：[src/main.py](src/main.py) → [src/gui/qt_widgets/main/main_widget.py](src/gui/qt_widgets/main/main_widget.py) → [src/gui/qt_widgets/main/home_widget.py](src/gui/qt_widgets/main/home_widget.py)（`init_processors`）→ [src/processor/baostock_processor.py](src/processor/baostock_processor.py)（`start_background_loading`）→ [src/thread/base_thread_worker.py](src/thread/base_thread_worker.py) → [src/manager/bao_stock_data_manager.py](src/manager/bao_stock_data_manager.py)（`load_1d_local_stock_data`）→ [src/gui/qt_widgets/market/market_home_widget.py](src/gui/qt_widgets/market/market_home_widget.py) → [src/gui/qt_widgets/market/market_widget.py](src/gui/qt_widgets/market/market_widget.py) → [src/gui/qt_widgets/MComponents/indicators/indicators_view_widget.py](src/gui/qt_widgets/MComponents/indicators/indicators_view_widget.py)。

### 5.2 首页按钮 → 下载/更新行情数据

```
HomeWidget 按钮点击（首页）
  └─ BaoStockProcessor.start_*_stock_data_background_update() / process_*_stock_data()
       └─ process_stock_data(board, period, task)
            └─ 遍历该板块每只股票：
                 ├─ process_and_save_daily_stock_data(code)      # 日线
                 ├─ process_and_save_weekly_stock_data(code)     # 周线
                 └─ process_and_save_minute_level_stock_data(code, level)  # 分钟线
                      └─ StockDbBase.save_bao_stock_data_to_db() # 写入 SQLite
```

AKShare 侧类似：`AKStockDataProcessor.get_stocks_info_and_save_to_db()` 拉取全 A 股票列表，`process_*` 系列拉取板块、市值、筹码分布等，最后写入 `StockInfoDBBase` / `StockDbBase`。

对应证据：[src/gui/qt_widgets/main/home_widget.py](src/gui/qt_widgets/main/home_widget.py)（各 `slot_btn_*` 槽函数）、[src/processor/baostock_processor.py](src/processor/baostock_processor.py)（`process_stock_data`、`process_minute_level_stock_data_with_board_type`）、[src/processor/ak_stock_data_processor.py](src/processor/ak_stock_data_processor.py)、[src/db_base/stock_db_base.py](src/db_base/stock_db_base.py)。

### 5.3 复盘回放 + 模拟交易（项目特色功能）

```
ReviewWidget（复盘页）
  └─ load_data(code, date)  （仅由“加载数据”/“随机加载”按钮触发）
       ├─ 远程只拉基周期（日线、5 分钟；get_load_periods / set_load_periods 可调整展示周期）
       │    ├─ 按顺序串行提交 BaostockDataFetchTask（baostock 单会话不可并发），任务返回已补名称与指标列的 DataFrame
       │    └─ 上级周期（10/15/30/45/60/90/120 分、周、月）由 period_aggregator 本地聚合生成
       ├─ IndicatorsViewWidget.set_stock_data(code, {全部周期: df})   # 一次性注入
       ├─ IndicatorsViewWidget.set_period_buttons_enabled(已加载周期) # 加载期间全禁用，完成后仅启用已加载周期
       ├─ IndicatorsViewWidget.set_current_period(comboBox 所选周期)  # 初始显示周期
       └─ IndicatorsViewWidget.init_animation(data, date)             # 定位到历史某天
            └─ update_chart(data, start_index)                        # 画当时的 K 线
  └─ 周期切换（复盘模式）：切换前按当前 as_of 重建目标周期并统一锚定；未注入/未覆盖周期回退并提示，不触发上层取数；
     进行中（未走完）bar 按 as_of 重建、周期内前进自动走完、时间跨周期传播，详见 docs/设计文档/复盘周期切换与聚合设计.md
  └─ 点击播放 → IndicatorsViewWidget.start_animation()
       └─ QTimer 逐步推进 → sig_current_animation_index_changed 信号
            └─ ReviewWidget.slot_current_animation_index_changed
                 ├─ 更新进度条/日期标签
                 └─ ReviewDemoTradingManager.update_trading_record(...)
                      # 用当前 K 线的最高/最低价撮合“买入/卖出挂单”
                      # 完成交易后发信号 → 刷新资产、收益率、交易记录列表
```

对应证据：[src/gui/qt_widgets/MComponents/review_widget.py](src/gui/qt_widgets/MComponents/review_widget.py)（`load_data`、`slot_btn_play_clicked`、`slot_current_animation_index_changed`）、[src/gui/qt_widgets/MComponents/indicators/indicators_view_widget.py](src/gui/qt_widgets/MComponents/indicators/indicators_view_widget.py)（`init_animation`、`start_animation`、`step_forward`）、[src/manager/review_demo_trading_manager.py](src/manager/review_demo_trading_manager.py)（`pending_order_buy/sell`、`update_trading_record`）。

## 6. 如何运行、测试、构建

### 6.1 环境准备

1. 安装 Python 3.10 或更高版本（README 明确要求）。
2. 创建虚拟环境并安装依赖（[README.md](README.md) 有完整步骤）：
   - Windows：`py -3.10 -m venv .venv` 后激活 `.venv\Scripts\activate`
   - 或使用 conda：`conda create --name myenv python=3.10`
   - 然后 `pip install -r requirements.txt`
3. 准备数据（首次运行必需，因为程序读的是本地数据）：
   - 方式一：运行 `scripts/run_baostock_data_update.bat` 慢慢下载；
   - 方式二：下载 README 里网盘链接的历史数据，把解压出的 `stocks` 文件夹放到 `data/database/` 下；
   - 也可以在程序界面的首页按需下载。

### 6.2 运行

**在项目根目录**执行：

```bash
python ./src/main.py
```

（Windows 激活虚拟环境后为 `.venv\Scripts\python ./src/main.py`。）

⚠️ 不要直接在 `src` 目录里运行 `python main.py`，否则 `./src/gui/.../Xxx.ui`、`./data/logs` 等相对路径会失效。

### 6.3 测试

**结论：已有基于 `unittest` 的自动化测试（纯合成数据、无网络依赖），从项目根目录运行：**

```bash
python -m unittest discover -s tests -v
```

- `tests/test_period_aggregator.py`：周期聚合器单测（交易时段切槽、跨午休 120m、部分槽、多周期倍数、自定义分钟）；
- `tests/test_review_period_switch.py`：复盘周期切换集成测试（离屏 Qt，覆盖加载锚定、全矩阵位置保持、盘中边界、进行中/自动走完、时间跨周期传播、未覆盖回退）。

CI：`.github/workflows/unittest.yml`（GitHub Actions，push/PR 到 `master`/`release/*` 自动运行 unittest）。

真实数据冒烟（可选，需联网）：`python scripts/smoke_review_baostock.py [--code sz.000615] [--date YYYY-MM-DD]`。

冒烟验证仍为：`python ./src/main.py` + 查看 `data/logs/`。

### 6.4 构建/资源编译

- **没有打包配置**：没有 `setup.py`、`pyproject.toml`、PyInstaller 的 `.spec` 文件，目前只能源码运行，不能直接“构建成 exe”。
- **资源文件编译**：如果修改了 `src/resources/resources.qrc` 或新增了图标/样式，需要重新生成 `resources_rc.py`：

```bash
python src/resources/auto_recompile_resources.py
```

这个脚本会把 `resources.qrc` 编译成 `src/resources/resources_rc.py`（PyQt5 下使用 `pyrcc5`）。注意 `resources_rc.py` 是生成文件，**不要手改**。

## 7. 哪些文件是高风险或不建议新手直接修改的

**结论：以下文件要么是“生成文件”、要么是“牵一发动全身”的核心，新手改动前一定要先看懂调用关系。**

| 文件 | 为什么不建议新手动 |
| --- | --- |
| [src/resources/resources_rc.py](src/resources/resources_rc.py) | 约 912KB 的 **Qt 资源编译生成文件**，手改没有任何意义且极易出错；要改请改 `resources.qrc` 后重新编译 |
| [src/processor/baostock_processor.py](src/processor/baostock_processor.py) | 约 1242 行，数据抓取核心：涉及网络、写库、后台线程、板块遍历，改动一处可能影响整个数据链路 |
| [src/db_base/stock_db_base.py](src/db_base/stock_db_base.py) / [src/db_base/stock_info_db_base.py](src/db_base/stock_info_db_base.py) | SQLite 建表、加列、改表结构都在这两层；**改动 schema 可能让已有本地数据报废** |
| [src/gui/qt_widgets/MComponents/indicators/indicators_view_widget.py](src/gui/qt_widgets/MComponents/indicators/indicators_view_widget.py) | 约 1164 行，K 线绘制、周期切换、回放动画全在这一个文件里，状态多、逻辑复杂 |
| [src/gui/qt_widgets/MComponents/review_widget.py](src/gui/qt_widgets/MComponents/review_widget.py) + [src/manager/review_demo_trading_manager.py](src/manager/review_demo_trading_manager.py) | 模拟交易的撮合和资金计算逻辑，涉及金钱数字，改错会得到错误的盈亏结果 |
| [src/main.py](src/main.py) | 入口的路径和 DPI 环境变量设置很“娇气”，改坏了整个程序可能起不来 |
| [src/manager/indicators_config_manager.py](src/manager/indicators_config_manager.py) / [src/common/common_api.py](src/common/common_api.py) | 都是几百上千行的“大杂烩”工具/配置文件，依赖面广 |
| [scripts/auto_update_baostrock_data.py](scripts/auto_update_baostrock_data.py) 等数据脚本 | 直接写 `data/database` 下的生产数据；脚本也包含与主程序互斥的进程检查逻辑，改动需谨慎 |
| 各类 `.ui` 文件 | `.ui` 是界面布局定义，与其配对的 `.py` 用 `uic.loadUi` 加载；手工在 `.py` 里加控件而不同步 `.ui`，运行时会报“找不到控件” |

## 8. 当前项目最缺少的文档或测试

**结论：最缺的是“自动化测试”和“面向新手的架构/接口文档”；其次是 README 承诺但缺失的贡献指南和打包配置。**

1. **自动化测试覆盖面仍不足**：已为复盘周期聚合/切换补充 `tests/`（unittest）并配置 GitHub Actions CI；指标计算（`stock_data_indicators.py`）、模拟交易撮合（`review_demo_trading_manager.py`）、数据库读写（`db_base`）仍缺单测。
2. **缺少架构/模块说明文档**：`docs/` 里目前只有效果图，没有架构图说明、模块关系图或“如何新增一个指标/新增一个数据源”的开发指南。
3. **README 承诺的 CONTRIBUTING.md 不存在**：README 里写了“贡献指南请参阅 CONTRIBUTING.md”，但仓库根目录没有这个文件。
4. **缺少数据库 Schema 文档**：`stock_db_base.py` 里有建表 SQL，但没有任何文档说明每张表（`stock_data_1d`、`stock_data_30m`、板块表等）的字段含义，新手指着表名很难猜。
5. **缺少打包/部署文档**：没有 `pyproject.toml`/`setup.py`/`.spec`，也没有“如何打包成 exe”的说明。
6. **存在“死配置”容易误导新人**：[src/config/logging_config.yaml](src/config/logging_config.yaml) 写得很完整，但 `main.py` 实际调用 `setup_logging(...)` 时并没有传入这个文件（走的是参数配置），新手可能以为改 yaml 就生效。
7. **依赖版本未锁定**：[requirements.txt](requirements.txt) 只有包名没有版本号，换个时间安装可能得到行为不同的版本，可复现性弱。

## 附：阅读代码时发现的小问题（供后续参考，不影响本文档结论）

以下问题在本次只读分析中被注意到，作为“后续可以清理”的线索列出，没有做任何修改：

- `src/main.py` 导入了 `QQmlApplicationEngine` 和 `MainBridge`，但从未使用（[src/main.py](src/main.py)）。
- `src/thread/baostock_data_fetch_task.py` 的 `BaostockDataFetchTask.execute()` 中写的是 `if TimePeriod == TimePeriod.DAY:`，这里把“类”和“枚举成员”比较，恒为 `False`，属于逻辑错误（[src/thread/baostock_data_fetch_task.py](src/thread/baostock_data_fetch_task.py)）。
- `src/gui/qt_widgets/main/home_widget.py` 的 `init_processors()` 在初始化失败时直接调用 `quit()` 退出程序，体验上比较粗暴（[src/gui/qt_widgets/main/home_widget.py](src/gui/qt_widgets/main/home_widget.py)）。
- `src/resources/config/config.ini` 放在资源目录里，但 `ConfigManager` 实际读写的是用户目录 `%APPDATA%\MPolicy\config.ini`（[src/manager/config_manager.py](src/manager/config_manager.py)），两者容易让人混淆。
- 大量模块使用“单例 + 全局实例”模式（如 `ProcessorController`、`default_task_pool`），新手需要先理解这个约定再改动。
