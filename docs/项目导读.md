# KLineReview 项目导读

> 本导读按 V1.0 收尾代码更新（2026-09-08，`release/1.0`，已合入 `master`）。路径均相对项目根目录。

## 一分钟看懂

KLineReview 是一个 **A 股 K 线回放复盘与模拟交易**桌面工具：从 Baostock 按需拉取股票 K 线，计算并绘制技术指标，把时间拨回历史某一天逐步回放，并在回放中模拟买卖、统计收益。

主窗口（[main_window.py](../src/gui/qt_widgets/main/main_window.py)）包含三个页面：

1. **首页（Home）**：弹幕随机选股/手动选股，也可接收复盘页随机结果。
2. **复盘（Review）**：输入代码/日期加载 K 线，周期切换、播放/暂停回放、模拟交易、收益曲线。
3. **设置（Settings）**：主题、强调色、语言、DPI/缩放、毛玻璃等。

## 启动与数据

必须在项目根目录运行：

```bash
python ./src/main.py
```

运行依赖相对路径（`.ui` 文件、`app/config/config.json`、`./data/logs`），从 `src` 等子目录启动会失败。

- 启动即登录 Baostock，并在后台获取股票代码/名称列表（[baostock_data_fetch_task.py](../src/thread/baostock_data_fetch_task.py) 的 `BaostockInfoFetchTask`）。
- 复盘页按需远程拉取基周期数据：当前默认只拉**日线**，周线/月线由 [period_aggregator.py](../src/processor/period_aggregator.py) 本地聚合；分钟级链路保留但默认注释（扩展方法见 [数据源适配接入设计.md](设计文档/数据源适配接入设计.md)）。
- 界面配置（主题/语言/缩放等）存于 `app/config/config.json`（[config.py](../src/common/config.py)，目录已被 git 忽略）；日志在 `data/logs/`。

## 复盘主链路

```text
ReviewWidget.load_data(code, date)
  └─ 串行提交 BaostockDataFetchTask 拉取缺失基周期（当前：日线）
       └─ 返回含名称/指标的 DataFrame
  └─ 用 period_aggregator 本地生成周线/月线等上级周期
  └─ IndicatorsViewWidget.set_stock_data(...) 统一注入
  └─ init_animation(data, date) 定位到复盘日
  └─ 播放/步进/周期切换 → 模拟交易撮合 → 收益/记录刷新
```

复盘周期切换的锚定、进行中 bar、时间跨周期传播等规则见 [复盘周期切换与聚合设计.md](设计文档/复盘周期切换与聚合设计.md)。

## 运行、测试与资源编译

```bash
# 自动化测试（无需网络）
python -m unittest discover -s tests -v

# 联网真实数据冒烟（可选）
python scripts/smoke_review_baostock.py --code sz.000615 --date YYYY-MM-DD

# 修改 resources.qrc / 图标 / QSS 后重新生成 resources_rc.py
python src/resources/auto_recompile_resources.py
```

CI（[unittest.yml](../.github/workflows/unittest.yml)）在 push/PR 到 `master`/`release/*` 时运行上述测试。

发布打包由 [release.yml](../.github/workflows/release.yml) 负责：向 `master`/`release/*` 打 `vX.Y.Z` tag 后，自动在 Windows/macOS 上执行 [KLineReview.spec](../packaging/KLineReview.spec) 构建 exe/dmg，并上传到 GitHub Release。本地也可先运行 `python packaging/make_icons.py` 后执行 `pyinstaller --noconfirm --clean packaging/KLineReview.spec`。
